# HonestDesk — состояние проекта

## Цель

HonestDesk — операторское WPF-приложение для управления HonestFlow через HonestLicenseServer.
До завершения HonestDesk изменения в HonestFlow не вносим.

## Работает

- Подключение к HonestLicenseServer по Admin API key; ключ хранится через DPAPI.
- Получение заявок поддержки и заявок регистрации устройств.
- Одобрение и отклонение регистрации устройств.
- Загрузка и редактирование клиентов.
- Загрузка и сохранение пароля продавца (`identificationCode`) и токена ЧЗ (`chzToken`).
- Загрузка глобальных и клиентских версий компонентов.
- Каталог доступных сборок и override-версий загружается из `/api/admin/assets`.
- Загрузка устройств, названий и адресов.
- Загрузка опубликованных лицензионных grants в редактор.
- Подпись и пакетная публикация лицензий с KeyId `primary-2026`.
- Продолжение частично выполненной публикации и повтор временных серверных ошибок.
- Асинхронный просмотр ограниченного хвоста журнала и ротация логов.
- Отдельно сохранена старая версия с Яндекс.Диском.

## Известные ограничения

- Статус обычной заявки поддержки нельзя изменить на сервере: endpoint отсутствует.
- RuDesktop-пароль и часть старых настроек пока не имеют полного серверного контракта.
- Старый manifest содержит глобальные операторские устройства; при публикации неприменимые связи безопасно пропускаются.
- После появления нового DeviceId устройство нужно добавить в лицензию и опубликовать grant.
