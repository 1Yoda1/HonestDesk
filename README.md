# HonestDesk

Windows-приложение для оператора поддержки HonestFlow. HonestDesk работает в
трее, читает заявки из отдельной папки Яндекс.Почты по IMAP, показывает
уведомления и запускает RuDesktop для подключения к клиенту.

## Возможности

- получение заявок из Яндекс.Почты по IMAP/SSL;
- поддержка человекочитаемого тела письма и JSON-блока;
- локальный список заявок без базы данных;
- уведомления Windows и работа в трее;
- поиск RuDesktop в стандартных каталогах и реестре;
- хранение пароля приложения через Windows DPAPI;
- локальное журналирование основных событий.

## Требования

- Windows 10/11;
- .NET 10 SDK для сборки;
- пароль приложения Яндекс.Почты;
- RuDesktop (для удалённого подключения).

## Сборка

```powershell
dotnet build .\HonestDesk.slnx
```

После первого запуска укажите параметры IMAP и папку заявок в окне настроек.
Настройки, зашифрованный пароль, состояние и журнал сохраняются в
`%APPDATA%\HonestDesk` и не входят в репозиторий.
