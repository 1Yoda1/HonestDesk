# HonestDesk

Современное WPF-приложение для оператора поддержки HonestFlow. HonestDesk работает в
трее, читает заявки из отдельной папки Яндекс.Почты по IMAP, показывает
уведомления и запускает RuDesktop для подключения к клиенту.

## Возможности

- получение заявок из Яндекс.Почты по IMAP/SSL;
- поддержка человекочитаемого тела письма и JSON-блока;
- локальный список заявок без базы данных;
- уведомления Windows и работа в трее;
- поиск RuDesktop в стандартных каталогах и реестре;
- хранение пароля приложения через Windows DPAPI;
- локальное журналирование основных событий.
- современный WPF-интерфейс с панелью состояния и быстрыми действиями.
- безопасная read-only карточка клиента из конфигурации ConfigEditor;
- встроенный WPF-редактор конфигурации в защищённой административной зоне.

## Интеграция с ConfigEditor

Выберите заявку и нажмите **Карточка клиента**. HonestDesk сопоставит клиента
по `ClientId`, ИНН или названию и покажет архитектуру, версии компонентов,
теги и состояние настроенных доступов. Значения паролей и токенов в карточке
не отображаются.

Для административных изменений нажмите **Администрирование**. При первом
запуске администратор Windows создаёт отдельный пароль. После авторизации
открывается новый WPF-редактор клиентов и глобальных версий.

Административная сессия действует 10 минут. После пяти ошибочных паролей вход
блокируется на 15 минут. Локальные черновики защищаются Windows DPAPI, а
действия записываются в отдельный журнал аудита.

В разделе **Лицензии** можно управлять клиентскими и операторскими
устройствами, доступными функциями, минимальной версией HonestFlow и
офлайн-периодом. Манифест сначала сохраняется и подписывается локально,
повторно проверяется публичным ключом и только затем публикуется отдельной
неизменяемой ревизией.

Общие модели и безопасное чтение конфигурации находятся в библиотеке
`HonestFlow.Config.Core`. Проверенная транспортная логика ConfigEditor
подключается как DLL; отдельный WinForms-интерфейс в HonestDesk не используется.

## Требования

- Windows 10/11;
- .NET 10 SDK для сборки;
- пароль приложения Яндекс.Почты;
- RuDesktop (для удалённого подключения).

## Сборка

```powershell
dotnet build .\HonestDesk.slnx
```

После первого запуска укажите параметры IMAP и папку заявок в окне настроек.
Настройки, зашифрованный пароль, состояние и журнал сохраняются в
`%APPDATA%\HonestDesk` и не входят в репозиторий.
